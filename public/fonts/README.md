# Font đóng gói sẵn

Mọi font trong thư mục này đều theo **SIL Open Font License 1.1**. Bản giấy phép
gốc của từng font nằm trong `licenses/` — OFL bắt buộc kèm theo mỗi khi phát hành
lại font, kể cả khi chỉ đưa lên một kho mã nguồn.

| File | Font | Nguồn |
| --- | --- | --- |
| `BeVietnamPro-Bold.ttf`, `BeVietnamPro-Regular.ttf` | Be Vietnam Pro | Google Fonts |
| `SourceSans3-Bold.otf` | Source Sans 3 | Adobe Fonts |
| `PatrickHand.ttf` | Patrick Hand | Google Fonts |
| `Lobster-Regular.ttf` | Lobster | Google Fonts |
| `Pacifico-Regular.ttf` | Pacifico | Google Fonts |
| `Charm.ttf` | Charm | Google Fonts |
| `DancingScript.ttf` | Dancing Script | Google Fonts |
| `Playball.ttf` | Playball | Google Fonts |
| `GreatVibes.ttf` | Great Vibes | Google Fonts |

Thêm font mới: chép file vào đây, thêm một dòng vào `fonts.json`, và **chép cả
giấy phép của nó vào `licenses/`**.
